# Logos

`aviteus-business-logo.png` is the official Aviteus Business logo, copied byte for byte from the live site (500 x 219 PNG, transparent background).

- Inks: slate bars (`slate`), orange bars and pulse line, wordmark in `logo-ink`. It is multi-colour and cannot be recoloured.
- Place it directly on white. On `night` or in Night Ledger, place it on the `plate` (`.av-logo--plate`).
- Minimum width 120px. Clear space `space-4` on every side.
- No vector version exists yet. Ask the brand owner for an SVG master before print work.
