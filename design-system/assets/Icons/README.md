# Icons

The service, feature and step icons from the live site, copied as supplied.

- Each icon is a round `blush` (#FFEEEA) tile with line art in `icon-ink` (#FA360A). The inks are baked in, so they cannot change colour with CSS.
- Sizes: 56px in FeatureList, 64px in ServiceCard.
- Always decorative: `alt=""` with a visible title next to it.
- `service-tax-payroll.svg` is used on the live site for both tax and payroll. A separate payroll icon is still needed.
- `step-*` icons belong to the old four-step process. The new ProcessSteps component uses numbered nodes instead; keep these for blog and social use.
