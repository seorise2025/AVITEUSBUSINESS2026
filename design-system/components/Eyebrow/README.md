# Eyebrow

A small uppercase line above a title, led by the node dot from the logo's circuit ends.

**Consumer provides:** 1 to 4 words of text.

- Style: `eyebrow` type style, `ember-ink` colour (on night: `ember-glow`).
- One eyebrow per section. It names the topic. The title below makes the promise.
- Write it as a label, not a sentence: "Payroll", "How we work", "Fixed fees".

**Do not** end it with a full stop or use it on its own without a title.
