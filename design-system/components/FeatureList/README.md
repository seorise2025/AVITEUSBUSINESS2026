# FeatureList

A vertical list of reasons to choose Aviteus, linked by a dashed `ember` connector between icons.

**Consumer provides:** 3 items, each with an icon, a title (max 4 words) and one sentence.

- Icon 56px, title `heading-3`, text `body` in `ink-body`.
- The connector is a dashed `stroke-pulse` line. It stops at the last item.
- Pair it with a photo on the other half of an about section.

**Do not** use more than 4 items or put links in the text.
