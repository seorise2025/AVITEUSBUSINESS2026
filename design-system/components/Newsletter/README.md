# Newsletter

An `ember-wash` panel with a promise and a one-line email form joined into a single pill.

**Consumer provides:** eyebrow, a title that says what arrives and how often, one line of reassurance, a hidden label for the input.

- The pill form gets a 2px `ember` ring when the input has focus.
- Name the newsletter. "The monthly ledger" beats "Subscribe to our newsletter".

**Do not** ask for a name or phone number here.
