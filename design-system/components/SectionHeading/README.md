# SectionHeading

The opening block of every section: eyebrow, title, one lead line and the short Pulse Line.

**Consumer provides:** eyebrow text, a title (max 10 words), an optional lead line (max 25 words).

- Title uses `heading-1`, lead uses `lead` in `ink-body`.
- Add `.av-heading--center` only for sections with a centred grid below (services, steps). Default is left aligned.
- Leave `space-7` between the heading block and the content under it.

**Do not** stack two headings, or put a button inside the heading block.
