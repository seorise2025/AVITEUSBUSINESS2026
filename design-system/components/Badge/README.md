# Badge

A small notched chip for credentials and plain facts: ICAEW, ACCA, CIMA, MTD ready.

Intentional addition: the source site states its credentials only inside a sentence. Trust marks work harder when they can be scanned.

**Consumer provides:** 1 to 2 words in capitals.

- `ember-wash` fill with `ink` text on light; `.av-badge--night` on night bands. Corner cut `cut-s`.
- Show at most 4 in a row, in the hero proof line or the footer.

**Do not** use badges as buttons or for marketing claims ("BEST PRICE").
