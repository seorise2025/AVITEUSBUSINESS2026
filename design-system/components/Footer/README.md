# Footer

A `night-deep` footer with the logo on its plate, quick links, and opening hours set as a ledger with dotted leaders.

**Consumer provides:** logo, address, 4 to 6 links, hours rows, legal links.

- Hours use the `code` style: label, dotted leader, value. It reads like a line in a set of accounts.
- Links are `on-night-muted`, hover to `on-night`.
- Keep the copyright year current.

**Do not** link "Privacy Policy" to the home page (the live site does this today), or add social icons that link nowhere.
