# PartnerStrip

A row of the software platforms Aviteus works in, shown as outlined pills.

**Consumer provides:** platform names, or official partner logo files where partner terms allow.

- In this system the names are set in the display face. In production, swap in each partner's official logo at one shared height (28px), greyscale at rest.
- Lead with the `code` style label "WE WORK IN".

**Do not** stretch or recolour partner logos, or list tools the team does not use daily.
