# ProcessSteps

Numbered nodes on a straight `ember` line, showing how a new client starts with Aviteus.

**Consumer provides:** 3 to 5 steps, each with a title (max 3 words) and one short line. Mark the step to highlight with `aria-current="step"`.

- Numbers are generated (01, 02, 03) in the `figures` family.
- The highlighted node fills `ember` with `on-ember` ink.
- Each line names a real action and a time or result ("within 48 hours").

**Do not** use filler text, icons inside the nodes, or more than 5 steps.
